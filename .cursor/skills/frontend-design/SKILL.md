# Frontend Design

Act as design lead. Distinctive point of view. One aesthetic risk you can justify.

## Defaults to refuse unless the brief demands them

1. Warm cream `#F4F1EA` + serif display + terracotta
2. Near-black + acid green or vermilion
3. Broadsheet hairline rules, zero radius, newspaper columns
4. Inter / Roboto / Arial / purple gradients on white / glassy cards

## Process

Pin subject, audience, one job. Then tokens: 4–6 named hex, display+body+utility faces, layout in one sentence, one signature element. If any token would appear on a generic SaaS, replace it.

Copy is UI. Active voice, sentence case, named by what the person does. Errors tell how to fix. Empty states invite an action.

Spend boldness in one place. Respect `prefers-reduced-motion`, keyboard focus, mobile.
